# Astraea MT5 — Branding Assets

This directory contains the official brand assets, logos, and favicons for **Astraea MT5**.

## Files Overview

- `logo.svg`: Primary dark-theme horizontal logo with icon and full typography.
- `logo-dark.svg`: High-contrast dark mode vector logo.
- `logo-light.svg`: Light background vector logo.
- `logo-icon.svg`: Square app/terminal icon.
- `favicon.svg`: 32x32 browser favicon.
- `BRAND_GUIDELINES.md`: Complete visual identity, color tokens, and typography guidelines.
